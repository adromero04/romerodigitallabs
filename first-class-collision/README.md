# 1st Class Collision

A fast, mobile-first static website for 1st Class Collision in Austin, Texas.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Structure

- `index.html` — semantic page content and business details
- `styles.css` — responsive styling
- `script.js` — header state and current footer year
- `assets/` — optimized client flyer artwork
